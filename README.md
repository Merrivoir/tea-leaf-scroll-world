# Поставки из Китая в Европу

Интерактивный презентационный сайт о полном цикле поставки: от поиска
производителя и переговоров с фабрикой до инспекции, консолидации,
авиадоставки, таможенного оформления и доставки на склад клиента.

Прокрутка страницы управляет видеорядом в обоих направлениях. При скролле
вверх ролики плавно перематываются назад.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте адрес, указанный в строке `Local` после запуска.

## Проверка

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run lint
```

Основной контент и логика находятся в `app/SupplyJourney.tsx`, оформление —
в `app/globals.css`, а исходные изображения и видео — в `public/media`.

Проект не использует авторизацию, базу данных, пользовательские аккаунты или
серверное хранилище.
